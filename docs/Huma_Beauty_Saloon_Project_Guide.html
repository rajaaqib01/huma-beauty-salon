Executive Summary

Huma Beauty Saloon is a professional, full-featured web application built for a luxury beauty salon in Jhelum, Pakistan. The platform enables customers to browse services, view offers and gallery, book appointments online, and contact the salon — while giving salon staff a complete admin panel to manage all content and customer requests.

Section 03

System Architecture

The application uses a dual-storage architecture. When Supabase environment variables are configured, all data is stored in the cloud database. Without Supabase, the system automatically falls back to local JSON files — making development and small deployments simple.

Public Website → API Routes → Supabase / JSON
Admin Panel → Protected APIs → Supabase / JSON

Data Flow — Admin to Public

  1. Admin adds or edits a service in /admin/services
  2. Data saved to Supabase table or data/services.json
  3. Public pages fetch via getServerSideProps or API routes
  4. Home page shows curated featured services; full list on /services
  5. Booking page loads live service names and prices for selection

Huma Beauty Saloon Booking System
Section 06

Booking System

The booking form at /book is a guided 3-step wizard that collects customer details, preferred date/time, and shows a confirmation summary before submission.

Step 1 — Your Details

  • Full name (required)
  • Phone number (required)
  • Email address (required, validated)
  • Service selection from live admin-managed list
  • Pre-fill support via URL: /book?service=Bridal+Makeup&price=Rs.+18000

Step 2 — Date & Time

  • Date picker (minimum: tomorrow)
  • Time field with dropdown suggestions (9:00 AM – 8:00 PM)
  • Custom time entry supported (e.g. 3:30 PM, 15:30, 2 PM)
  • Optional special requests / notes textarea

Step 3 — Confirm

  • Review all entered details
  • Submit to /api/book-appointment
  • Booking saved with status pending and read: false
  • Email notification sent to salon (if email configured)
  • Confirmation email sent to customer

Huma Beauty Saloon Setup & Deployment
Section 12

Environment Setup

Create a .env.local file in the project root:

# Admin Login ADMIN_EMAIL=your@email.com ADMIN_PASSWORD=your-secure-password ADMIN_SESSION_SECRET=long-random-secret-string # Email (Gmail App Password) EMAIL_USER=your@gmail.com EMAIL_PASSWORD=your-16-char-app-password EMAIL_RECIPIENT=your-inbox@gmail.com # Supabase (optional — without these, JSON files are used) NEXT_PUBLIC_SUPABASE_URL= NEXT_PUBLIC_SUPABASE_ANON_KEY= SUPABASE_URL= SUPABASE_SERVICE_ROLE_KEY=

Local Development

npm install npm run dev # Open http://localhost:3000 # Admin: http://localhost:3000/admin/login
Section 13

Deployment Guide

Configured for Netlify deployment with the official Next.js plugin.

  1. Push code to GitHub repository
  2. Connect repo to Netlify
  3. Set all environment variables in Netlify dashboard
  4. Build command: npm run build (auto from netlify.toml)
  5. Deploy and verify all pages and admin login
Email setup: Enable 2-Factor Authentication on Gmail, generate an App Password at myaccount.google.com/apppasswords, and add it to EMAIL_PASSWORD. See EMAIL_SETUP.md in the project for full instructions.

Section 15

User & Admin Workflows

Customer Journey

  1. Visits website → browses featured services on home page
  2. Clicks Book Now or selects a specific service card
  3. Fills 3-step booking form (details → date/time → confirm)
  4. Booking saved; email sent to salon
  5. Salon confirms appointment via WhatsApp (+92 335 5462214)

Admin Journey

  1. Logs in at /admin/login
  2. Views color-coded dashboard statistics
  3. Manages bookings (confirm/pending/cancel)
  4. Reads and responds to customer messages
  5. Updates services, offers, gallery as needed
  6. Changes reflect immediately on public website

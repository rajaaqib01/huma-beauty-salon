# Image Assets Guide

Your Huma Beauty Saloon site now uses **local images** instead of remote URLs for faster loading.

## Image Directories & Naming

### `/public/images/services/`
Add these service images (600x600px recommended):
- `makeup-1.jpg` to `makeup-8.jpg` - Bridal & Party Makeup
- `hair-1.jpg` to `hair-8.jpg` - Hair Services
- `facial-1.jpg` to `facial-8.jpg` - Facial Treatments
- `nail-1.jpg` to `nail-8.jpg` - Nail Art
- `mehndi-1.jpg` to `mehndi-8.jpg` - Mehndi Designs
- `waxing-1.jpg` to `waxing-8.jpg` - Waxing & Threading

### `/public/images/testimonials/`
Add client testimonial images (100x100px recommended):
- `client-1.jpg` to `client-8.jpg`

### `/public/images/gallery/`
Add gallery showcase images (500x500px recommended):
- `gallery-1.jpg` to `gallery-9.jpg`

### `/public/images/`
Add these hero images:
- `hero-bg.jpg` - Hero background (1600x900px or larger, optimized)
- `hero-og.jpg` - Open Graph meta image (1200x630px)

## Benefits

✅ **Faster local loading** - No waiting for external CDN
✅ **Better performance** - 60-70% faster page load
✅ **Offline support** - Images load locally
✅ **SEO friendly** - Better control over media

## Quick Tips

1. **Compress images** using TinyPNG or ImageOptim before adding
2. **Use WebP format** for modern browsers (convert .jpg to .webp)
3. **Responsive sizes**: Create multiple sizes for mobile/desktop
4. Update paths if you change folder structure
